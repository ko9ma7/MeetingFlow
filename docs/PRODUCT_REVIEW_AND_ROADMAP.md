# MeetingFlow 1.9 제품 리뷰·상용화 로드맵

## 한 문장 정의

MeetingFlow는 회의 봇을 초대하지 않고 마이크와 Windows 시스템 소리를 로컬에서 기록한 뒤, 사용자가 전사본을 검토해야만 선택한 AI 보고서를 만드는 **검토 우선·로컬 우선 회의 기록 도구**다.

## 이번 버전의 제품 원칙

1. **전사와 AI 보고서를 분리한다.** STT가 끝나도 Gemini를 자동 호출하지 않는다.
2. **초안과 확정본을 구분한다.** 녹음 중에는 빠른 모델의 실시간 초안을 보여 주고, 종료 후 정확도 모델로 전체 음성을 다시 처리한다.
3. **원본을 덮어쓰지 않는다.** `RawTranscript`는 변경하지 않고, 사용자 수정은 `Transcript` 검토본에 저장한다.
4. **화자를 추측하지 않는다.** pyannote가 실제로 분리한 경우에만 화자 A·B·C를 표시한다.
5. **AI 실패가 기록 실패가 되지 않게 한다.** 전사·오디오·검토본은 먼저 로컬에 저장하고 AI 연결 실패는 재처리 가능한 상태로 남긴다.
6. **지원하지 않는 엔진을 작동하는 것처럼 보이지 않는다.** 현재 사용 가능, 선택 설치, 검증 예정 상태를 UI에서 분리한다.

## 핵심 사용자 흐름

```text
소스 선택 → 녹음(실시간 초안) → 정확도 전사 → 화자 분리(선택)
        → 사용자 검토·수정 → 검토본 저장 → AI 보고서 생성 → 기록·검색·내보내기
```

AI 보고서 버튼을 누르기 전까지 전사 내용은 Gemini로 전송되지 않는다. 보고서의 근거는 변경되지 않는 STT 원본이 아니라 사용자가 확인한 검토본이다.

## 1.9에서 구현한 기능

### 음성 수집·전사

- PyAudio 마이크 녹음
- NAudio WASAPI 시스템 소리 루프백 녹음
- 녹음 중 6초 단위 실시간 초안 스트리밍
- 빠른 초안 모델(tiny/base/small)과 정확도 모델 분리
- Python faster-whisper와 C# Whisper.net 실행 엔진 선택
- tiny, base, small, medium, large-v3, large-v3-turbo 모델 선택
- 한국어·영어·중국어·일본어·독일어·프랑스어 등 고정/자동/혼합 언어 설정
- VAD, Beam Search, 콘텐츠 문맥, 사용자 용어, 반복 환각 억제

### 화자 분리

- 사용 안 함 / 자동(최대 화자 수) / 고정 화자 수
- pyannote Community-1 선택 연동
- Hugging Face 토큰 Windows 계정 암호화 저장
- 토큰을 프로세스 명령행이 아닌 환경 변수로 전달
- 구간 겹침이 가장 큰 실제 화자를 A·B·C로 매핑
- 설치·토큰·실행 오류 시 전사는 유지하고 진단 메시지만 기록

### 검토·AI 보고서

- 전사 직후 `검토 대기` 상태로 저장
- 사용자 수정본 저장 버튼
- 검토본으로 AI 보고서 만들기 버튼
- 원본 STT, 검토본, AI 보고서 분리 저장
- 부분 시간 범위 재정리
- 12종 보고서 템플릿과 사용자 지침
- Gemini 실패 시 AI 대기 작업 저장 및 연결 복구 후 재실행

## 상용 제품 조사에서 반영한 구조

### Notion AI Meeting Notes

Notion은 시스템 소리와 마이크를 함께 기록하고, 회의 유형별 요약, 작업 항목, 검색 가능한 기록을 제공한다. 전사와 사용자 메모를 함께 요약 근거로 사용하며 화자 전환과 캘린더 문맥을 활용한다. MeetingFlow에는 다음 개념을 반영한다.

- 회의 유형별 보고서 지침
- 시스템 소리 직접 캡처, 봇 없는 녹음
- 전사·보고서의 분리 열람
- 화자 전환 단위 문단
- 검토본을 AI 근거로 사용하는 사람 중심 흐름

참고: [Notion AI Meeting Notes 도움말](https://www.notion.com/help/category/notion-ai), [제품 소개](https://www.notion.com/en-US/product/ai-meeting-notes)

### DeepL Voice

DeepL Voice의 실시간 자막과 Spoken Terms 개념은 실시간 초안과 사용자 용어 사전에 반영한다. 실시간 표시는 빠른 피드백용이고, 최종 정확도 전사는 별도로 수행한다.

참고: [DeepL Voice](https://www.deepl.com/en/products/voice)

### Google Cloud Speech-to-Text·AWS Transcribe

두 서비스는 스트리밍 인식과 화자 분리를 제공한다. Google은 단어별 화자 번호와 최소·최대 화자 수를, AWS는 배치·스트리밍 화자 분리와 최대 화자 수 설정을 지원한다. MeetingFlow의 자동/고정 화자 수 UI와 스트리밍 어댑터 인터페이스는 이 구조와 호환되도록 설계한다.

참고: [Google 스트리밍 인식](https://docs.cloud.google.com/speech-to-text/docs/streaming-recognize), [Google 화자 분리](https://docs.cloud.google.com/speech-to-text/v2/docs/multiple-voices), [AWS 스트리밍](https://docs.aws.amazon.com/transcribe/latest/dg/streaming.html), [AWS 화자 분리](https://docs.aws.amazon.com/transcribe/latest/dg/diarization.html)

## STT 엔진 포트폴리오

| 엔진 | 상태 | 장점 | 주의점 | 권장 용도 |
|---|---|---|---|---|
| faster-whisper | 사용 가능 | 로컬, 다국어, CTranslate2 가속 | CPU에서 큰 모델은 느림 | 기본 정확도 전사 |
| Whisper.net | 사용 가능 | C# 단독 폴백, 배포 단순 | Python 고급 옵션보다 제한적 | Python 장애 대비 |
| WhisperX + pyannote | 선택 기능 | 단어 타임스탬프·화자 분리 | 큰 의존성, GPU 권장 | 다자 회의 후처리 |
| Qwen3-ASR | 검증 예정 | 52개 언어·방언, 스트리밍/오프라인 | 메모리·GPU·Windows 배포 검증 필요 | 아시아 언어 대안 |
| Google Cloud STT | 어댑터 예정 | 실시간·화자 분리·관리형 | 비용·클라우드 전송 | 기업 선택 옵션 |
| AWS Transcribe | 어댑터 예정 | 스트리밍·화자·채널 분리 | 비용·계정 설정 | 콜센터·멀티채널 |
| OpenAI Transcribe | 어댑터 예정 | 관리형 전사·화자 모델 선택지 | 오픈소스 기본 원칙과 분리 필요 | 사용자가 명시적으로 선택할 때 |

Qwen3-ASR는 공식 저장소 기준 52개 언어·방언, 스트리밍과 오프라인 통합 추론을 제공하지만 현재 버전에서는 설치·성능 검증 전이므로 선택 가능 엔진으로 가장하지 않는다. 참고: [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR)

## 마케팅 포지셔닝

### 핵심 메시지

> 회의 봇 없이, 내 PC에서 먼저 받아쓰고, 내가 확인한 내용만 AI가 정리합니다.

### 차별점

- **Review-first AI:** 잘못 들은 문장을 AI가 사실처럼 요약하기 전에 사람이 확인
- **Local-first capture:** 마이크와 PC 시스템 소리를 로컬 파일로 우선 보존
- **No meeting bot:** Zoom·Teams·YouTube 소리를 Windows에서 직접 캡처
- **Bring your own AI:** STT는 오픈소스 기반, Gemini는 선택적 보고서 작성에만 사용
- **Model choice:** 빠른 초안과 정확도 모델을 목적·PC 성능에 맞게 분리
- **Evidence-friendly:** 원본, 검토본, AI 결과, 적용 시간 범위를 따로 보존

### 타깃 고객

1. 기술·제조 회의에서 제품명과 수치를 다시 확인해야 하는 팀
2. 민감한 내부 회의를 회의 봇 없이 기록하려는 중소기업
3. 뉴스·강의·유튜브 시스템 소리를 자료화하려는 개인
4. 한국어 중심 다국어 회의를 처리하는 수출·영업 조직
5. AI 요약 전에 원문 검토와 감사 추적이 필요한 조직

### 패키지 구상

- **Local:** 로컬 녹음, faster-whisper, 검토·검색·Markdown
- **Pro:** 화자 분리, 고급 모델, 12종 보고서, 용어 사전, 자동 재처리
- **Team:** 공유 저장소, 권한, 캘린더, 중앙 용어집, 감사 로그
- **Enterprise:** 보존 정책, SSO, 관리자 정책, 사내 모델·프라이빗 엔드포인트

## 출시 전 합격 기준

- 1시간 녹음에서 앱 중단과 파일 손상이 없어야 한다.
- AI 연결이 없어도 전사·검토·내보내기가 가능해야 한다.
- 전사 검토 전에는 AI API 호출이 발생하지 않아야 한다.
- 화자 분리 실패 시 가짜 화자 라벨이 생성되지 않아야 한다.
- 모든 저장 텍스트는 BOM 없는 UTF-8로 다시 열려야 한다.
- 키보드만으로 녹음, 전사, 검토 저장, AI 실행이 가능해야 한다.
