# MeetingFlow v1.9.0

MeetingFlow의 첫 공개 프리뷰 릴리스입니다. 로컬 녹음과 오픈소스 STT, 사용자 검토, 선택형 Gemini 보고서 생성을 하나의 Windows 작업 흐름으로 구성했습니다.

## 주요 기능

- 마이크와 Windows 시스템 소리 녹음
- 녹음 중 실시간 전사와 로컬 체크포인트
- faster-whisper CPU `int8` 전사
- `small`, `medium`, `large-v3-turbo` 품질 프리셋
- 문장 인식 즉시 진행률과 확정 전사 표시
- 한국어 중심 다국어 고정·자동·혼합 모드
- 선택형 pyannote 화자 분리
- 원본, 검토본, AI 보고서 분리 저장
- 12종 Gemini 보고서 템플릿
- AI 연결 실패 작업 재처리
- Markdown 내보내기

## v1.9.0 개선 사항

- CPU 최고 프리셋을 `large-v3`에서 `large-v3-turbo`로 변경했습니다.
- CPU 스레드를 프리셋별 6·8·10개로 제한했습니다.
- 전체 전사가 끝날 때까지 2%에 머물던 진행률을 문장별 스트리밍 방식으로 수정했습니다.
- 모델 다운로드와 실제 전사 단계를 구분해 표시합니다.
- 중첩 탭 대신 기록 → 자동 전사 → 원문 검토 → AI 보고서 단계형 UI를 적용했습니다.
- 파일 열기와 저장 창의 소유자를 지정해 포커스 복귀를 개선했습니다.
- README, 사용 가이드, 개인정보·보안 안내를 공개 배포 기준으로 정리했습니다.

## 검증

- .NET Release 빌드 성공
- 자동 테스트 12개 통과
- Python 3.13, PyAudio, faster-whisper 상태 검사 통과
- 114.5초 한국어 시스템 오디오 샘플에서 캐시된 `medium` 45.3초, `large-v3-turbo` 33.5초

성능 수치는 Ryzen 9 5950X CPU의 한 번의 로컬 측정이며 오디오, 모델 캐시, 저장 장치와 시스템 부하에 따라 달라집니다. 검증에 사용한 음원과 전사 내용은 저장소 및 릴리스에 포함하지 않습니다.

## 알려진 제한 사항

- 설치 프로그램과 코드 서명이 없습니다.
- Python 환경은 별도 설치 스크립트로 준비해야 합니다.
- 화자 분리는 선택 설치이며 CPU에서 느릴 수 있습니다.
- 장시간 녹음 복구와 메모리 검증이 더 필요합니다.
- 마이크와 시스템 소리 동시 믹스는 아직 지원하지 않습니다.
- 외부 협업 도구와 캘린더 연동은 구현 전입니다.
