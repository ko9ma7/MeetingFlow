# MeetingFlow v2.0.0

## STT 엔진

- faster-whisper 빠른 확정, CrisperWhisper 2.0 정밀 후처리, 이중 검증, Whisper.net 폴백을 선택할 수 있습니다.
- CrisperWhisper 모델, intended/verbatim 출력, 1·2·5·10분 장문 안전 구간을 설정할 수 있습니다.
- Python 3.13 faster-whisper와 Python 3.12 CrisperWhisper를 분리해 패키지 충돌을 막았습니다.

## 장시간 회의 안정성

- 실시간 초안 처리 큐를 1개로 제한해 CPU가 느릴 때 메모리와 임시 파일이 계속 쌓이지 않습니다.
- 건너뛴 실시간 구간은 원본 오디오에 남고 종료 후 확정 전사에서 복구합니다.
- 확정 전사 중 부분 결과를 15초마다 저장하며 Crisper 장문 구간 일부가 실패해도 성공 구간을 보존합니다.
- 이전 문맥 전파를 끄고 반복·저정보·무음 환각 필터와 임계값을 적용했습니다.

## 검토와 진단

- 두 엔진 결과를 시간 구간별로 비교하고 평균 일치도와 검토 필요 구간 수를 표시합니다.
- 보조 전사, 처리 배속, 처리 시간, 반복 제거 및 실패 경고를 회의 기록과 Markdown에 보존합니다.
- 녹음 시작 전 참석자 고지 확인을 요구합니다.
