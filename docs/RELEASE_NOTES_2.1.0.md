# MeetingFlow 2.1.0

## 실시간 회의 기록

- 실시간 입력을 8초 단일 처리에서 4초 순차 대기열로 변경했습니다.
- CPU 지연 시 최대 12개 구간(약 48초)을 순서대로 보존하며, 초과분은 원본 오디오에서 종료 후 확정합니다.
- 실시간 전사창을 녹음 중 바로 수정할 수 있고 수정본도 체크포인트에 자동 저장합니다.
- 무음·노이즈 구간은 문장으로 만들지 않고 현재 상태와 남은 대기 구간을 표시합니다.
- `tiny`/`base` 실시간 초안은 beam 1을 사용해 CPU 응답성을 우선합니다.

## 장시간 전사

- CrisperWhisper 구간을 15·30·60·120초로 선택해 앞 구간 결과부터 확인할 수 있습니다.
- 일반 회의실, 소음 공간, 작은 목소리용 VAD 프로필을 추가했습니다.
- 반복·환각 억제, 구간 실패 후 계속 처리, 원본 오디오 보존은 그대로 유지합니다.

## AI 보고서

- Gemini, OpenAI Responses API, Anthropic Messages API, OpenAI 호환 Chat Completions 서버를 선택할 수 있습니다.
- 공급자별 API 키를 Windows DPAPI로 각각 암호화 저장합니다.
- OpenAI 요청은 `store: false`와 JSON Schema를 사용합니다.
- AI에는 오디오가 아니라 사용자가 검토한 지정 범위의 텍스트만 전송합니다.

## 검증

- 합성 회의를 실제 faster-whisper `base` 모델로 4초씩 순차 처리했습니다.
- 첫 구간 1.31초, 이후 구간 0.48~0.55초였고, 2개 무음 구간 모두 음성 없음으로 판정했습니다.
- Release 빌드와 전체 자동 테스트, Windows UI 수동 검증을 통과했습니다.
