# MeetingFlow 2.2.0

## 회의 중 확인·수정

- 실시간 초안 구간을 4초에서 약 3초로 줄여 첫 문장을 더 빨리 표시합니다.
- CPU가 밀리면 36초까지 순서대로 대기시키고, 초과 구간은 원본 오디오를 사용해 종료 후 확정합니다.
- 무음·노이즈는 VAD로 제외하고, 사용자 수정본은 녹음 중 로컬 체크포인트에 계속 저장합니다.
- 홈 화면에서 실시간 엔진 준비 여부와 첫 결과 예상 시점을 바로 확인할 수 있습니다.

## 자연스러운 회의 흐름

- 홈의 보고서·AI 수준·화자 설정을 변경 즉시 저장합니다.
- 이전 설정 파일의 누락·null 값을 시작 시 안전하게 복구합니다.
- 화면 체험 결과에 `체험 종료 · 새 회의` 버튼을 추가했습니다.
- 저장된 과거 회의를 `원문·화자 이름 수정`으로 다시 열 수 있습니다.

## 화자 이름 연결

- 화자 ID A/B/C/D를 안정적으로 보존하면서 `A(김과장)`처럼 실제 이름을 연결합니다.
- 이름 변경은 같은 화자의 모든 문장, AI 보고서 입력, Markdown 내보내기에 함께 반영됩니다.
- 이름이 포함된 전사본을 다시 편집해도 내부 화자 ID를 잃지 않습니다.

## 참고 기술 검토

- RealtimeSTT의 VAD·순차 콜백 설계는 현재 faster-whisper 실시간 경로와 같은 방향이어서 별도 중복 런타임을 추가하지 않았습니다.
- Moonshine은 저지연 스트리밍과 화자 기능이 유망하지만 한국어 모델의 별도 비상업 라이선스 확인이 필요해 기본 엔진으로 묶지 않았습니다.
- capcut-tts-api는 TTS이고 STTextView-Plugin-Neon은 Apple용 텍스트 편집 플러그인이므로 Windows WPF STT 실행 엔진에는 포함하지 않았습니다.

## 검증

- Release 빌드와 전체 자동 테스트 16개를 통과했습니다.
- 실제 Windows 앱에서 Python 엔진 준비 표시, 3초 구간 실시간 초안, 편집 UI, 화자 이름 UI와 결과 화면을 확인했습니다.
