# MeetingFlow 2.2.1

이번 버전은 녹음은 남았지만 전사 데이터가 비어 있는 회의를 복구하고, 결과 화면에서 빠져나오지 못하던 문제를 해결한다.

## 변경 사항

- 결과/검토 화면에 `← 녹음 화면`을 항상 표시하고, 사이드바의 `새 회의`도 어느 단계에서나 첫 화면으로 돌아가게 수정
- 전사가 비어 있지만 WAV가 남아 있는 회의를 `STT 재처리 필요`로 표시
- 회의 기록에서 `저장된 오디오 재전사`로 동일한 기록을 복구하는 기능 추가
- 전사 데이터가 실제로 있을 때만 원문·화자 수정 및 AI 보고서 생성 버튼 활성화
- 재전사 시 기존 시작 시각과 회의 ID를 유지해 중복 기록이 생기지 않도록 수정
- 사용자가 전사를 취소한 경우 복구 가능한 상태를 기록에 저장
- 창 제목과 사이드바에 실행 버전 표시
- 고정 설치 위치와 바탕화면 바로가기를 만드는 설치 스크립트 추가
- RealtimeSTT, Moonshine, CrisperWhisper 및 함께 제공된 비-STT 프로젝트 비교 문서 추가

## 복구 방법

1. `회의 기록`에서 전사 내용이 비어 있는 회의를 선택한다.
2. 원본 오디오가 남아 있으면 `저장된 오디오 재전사`가 활성화된다.
3. 처리 중에는 앞에서부터 원문이 표시되고, 취소해도 같은 버튼으로 다시 시작할 수 있다.

`scripts\install-meetingflow.ps1 -SetUpPython`을 실행하면 `%LOCALAPPDATA%\Programs\MeetingFlow`에 설치하고 바탕화면의 `MeetingFlow` 바로가기를 최신 버전으로 연결한다.
