# MeetingFlow 사용 가이드

## 1. 처음 실행하기

1. Python 3.13과 .NET 8 Desktop Runtime을 설치합니다.
2. 프로젝트 또는 릴리스 폴더에서 `scripts/setup-python.ps1`을 실행합니다.
3. 상태 표시가 `PyAudio 준비 · AI 설정됨/미설정`으로 바뀌는지 확인합니다.
4. AI 보고서를 사용하지 않는다면 API 키 없이 바로 녹음할 수 있습니다.

## 2. 마이크 회의 기록

1. `새 회의`에서 제목과 기록 상황을 선택합니다.
2. `마이크 입력`과 사용할 PyAudio 장치를 선택합니다.
3. STT 품질은 먼저 `고정밀 · CPU 권장`을 사용합니다.
4. `미팅 기록 시작`을 누릅니다.
5. 약 4초 뒤부터 실시간 저장 전사가 앞에서부터 나타나는지 확인합니다. 잘못된 문장은 그 자리에서 바로 수정할 수 있습니다.
6. 회의가 끝나면 `종료하고 자동 확정`을 누릅니다.

녹음 중 표시되는 텍스트는 빠른 초안입니다. 확정 전사는 저장된 전체 오디오를 다시 처리하므로 내용과 타임스탬프가 달라질 수 있습니다.

무음은 오디오 원본에는 그대로 보존하지만 전사 문장에서는 제외합니다. `무음·노이즈 감지`는 일반 회의실의 `균형`, 에어컨·카페 소음이 큰 곳의 `소음 많은 공간`, 멀거나 작은 목소리의 `작은 목소리 우선` 중에서 선택합니다. 작은 목소리 우선은 잡음을 말로 오인식할 가능성이 조금 높습니다.

## 3. PC에서 재생되는 소리 기록

YouTube, 강의, 브라우저 영상처럼 PC에서 재생되는 소리는 `시스템 소리 · 스피커 루프백`을 선택합니다.

1. 재생 장치를 선택합니다.
2. 영상이나 회의를 재생하기 전에 MeetingFlow 녹음을 시작합니다.
3. Windows와 플레이어의 음량을 확인합니다.
4. 재생이 끝난 뒤 녹음을 종료합니다.

루프백은 선택한 출력 장치의 소리를 직접 기록합니다. 마이크 음성은 기본적으로 포함하지 않습니다.

## 4. 기존 오디오 가져오기

1. `오디오 파일 가져오기`를 누릅니다.
2. WAV, MP3, M4A, FLAC 또는 OGG 파일을 선택합니다.
3. 전체 길이와 AI 보고서 적용 범위를 확인합니다.
4. 전사를 시작합니다.

파일 선택 창은 MeetingFlow에 종속된 모달 창으로 열리며 완료 후 앱으로 포커스가 돌아옵니다.

## 5. 전사 품질 선택

- `빠른 확인`: 긴 회의나 낮은 사양 PC에서 빠르게 내용을 확인합니다.
- `고정밀 권장`: 한국어 회의와 뉴스의 기본 선택입니다.
- `터보 고정밀`: 더 많은 CPU와 메모리를 사용하지만 큰 모델 대비 빠른 고정밀 전사를 제공합니다.

처음 사용하는 모델은 자동으로 내려받기 때문에 전사보다 다운로드가 더 오래 걸릴 수 있습니다. 다음 실행부터는 로컬 캐시를 사용합니다.

## 6. 원문 검토

확정 전사가 끝나면 다음 순서로 검토합니다.

1. 고유명사, 숫자, 날짜, 담당자 이름을 확인합니다.
2. 잘못 인식한 문장을 수정합니다.
3. 화자 분리를 사용했다면 A·B·C 구간을 확인합니다.
4. `수정한 원문 저장`을 누릅니다.

변경되지 않는 STT 원본은 별도로 보존됩니다. AI 보고서는 사용자가 저장한 검토본을 근거로 사용합니다.

## 7. AI 보고서 만들기

1. 보고서 유형을 선택합니다.
2. 필요한 경우 시작·종료 시간을 조정합니다.
3. `검토본으로 AI 보고서 만들기`를 누릅니다.
4. 결과에서 결정사항, 담당자, 기한이 원문과 일치하는지 확인합니다.

선택한 AI 연결에 실패하면 로컬 데이터는 유지되고 AI 작업은 재처리 가능한 상태로 남습니다.

설정에서 Gemini, OpenAI, Anthropic 또는 OpenAI 호환 서버를 선택할 수 있습니다. 공급자별 키는 따로 암호화 저장되며, AI에는 오디오가 아니라 사용자가 검토한 텍스트 범위만 전송됩니다.

## 8. 화자 분리

화자 분리는 선택 기능입니다. [화자 분리 설치 가이드](SPEAKER_DIARIZATION_SETUP.md)에 따라 pyannote와 Hugging Face 토큰을 설정합니다.

- `자동 감지`: 입력한 수를 최대 화자 수로 사용합니다.
- `화자 수 고정`: 정확한 참가자 수를 알고 있을 때 사용합니다.
- `사용 안 함`: 가장 빠르고 메모리를 적게 사용합니다.

## 9. 내보내기와 백업

회의 기록에서 항목을 선택하고 `Markdown 내보내기`를 누릅니다. 내보낸 문서에는 AI 보고서, 검토본, 원본 STT, 실시간 저장본이 구분되어 포함됩니다.

백업이 필요하면 `%LOCALAPPDATA%\MeetingFlow\` 폴더를 안전한 위치에 복사하세요. 이 폴더에는 민감한 회의 데이터가 포함될 수 있습니다.

## 10. 문제 해결

### 진행률이 모델 준비 단계에 오래 머무는 경우

최초 모델 다운로드인지 확인합니다. 모델 크기는 약 0.48GB에서 1.62GB이며 네트워크에 따라 수 분이 걸릴 수 있습니다.

### CPU 사용량이 높은 경우

`빠른 확인` 또는 `고정밀 권장`을 선택하고 화자 분리를 끕니다. STT는 로컬 CPU 연산이므로 처리 중 사용량이 증가하는 것은 정상입니다.

### 소리가 인식되지 않는 경우

- 마이크 권한과 입력 장치를 확인합니다.
- 시스템 소리는 실제 재생 중인 출력 장치를 선택합니다.
- 평균 음량 경고를 확인합니다.
- 주 언어를 자동이 아닌 고정으로 설정해 다시 처리합니다.

### 반복 문자나 존재하지 않는 문장이 나오는 경우

입력 음량, 긴 무음, 배경 음악을 확인하고 반복 환각 억제를 켭니다. 확정 전사에서도 문제가 반복되면 더 큰 모델보다 먼저 녹음 품질을 개선하는 것이 효과적입니다.
